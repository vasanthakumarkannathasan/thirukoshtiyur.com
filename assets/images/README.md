# Images Directory

Please place temple images in the following subdirectories:

## Directory Structure

- `hero/` - Hero section background images (high resolution, 1920x1080 recommended)
- `logo/` - Temple logo and favicon
- `temple/` - Temple exterior and interior photos
- `deities/` - Deity images
- `festivals/` - Festival celebration photos
- `events/` - Event photos
- `gallery/` - General gallery photos

## Image Optimization Guidelines

1. **Format**: Use WebP for best compression, with JPG fallback
2. **Size**: Optimize images before uploading
   - Hero images: max 500KB
   - Gallery images: max 300KB
   - Thumbnails: max 50KB
3. **Dimensions**: 
   - Hero: 1920x1080px
   - Gallery: 800x600px
   - Thumbnails: 300x225px
4. **Naming**: Use descriptive names
   - `temple-front-view-2026.jpg`
   - `krishna-jayanthi-2026-08.jpg`

## Tools for Optimization

- **Online**: TinyPNG, Squoosh.app
- **Desktop**: ImageOptim (Mac), FileOptimizer (Windows)
